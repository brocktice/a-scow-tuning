Pre-bend
Pre-bend — “intermediates” / diamonds: measured with a string down the back of the tunnel, read at the spar midpoint. It works with the wind — more bend as it builds, to flatten the main and depower: ≈4–4.5″ light · ≈5″ all-purpose · 5–5.5″ heavy. Some skippers move it with the breeze; others set one number and leave it. (Values are North's reference — swap in Louis's targets and note whether he adjusts or fixes it.)

On-the-water notes

  • Buddy: too much mast bend above 18 kn — tighten lowers 2 turns.
  • Andy: main traveler up 3″ in 0–6, main eased for twist. Keep traveler centered until everyone's on the rail.
  • Depowering priority: 1) vang, 2) fine tune, 3) traveler down. Return to base at the end of the racing day.
Hull quirk (per L. Hill): legacy A Scow molds run ~5⁄8″ higher to starboard, so a symmetric rig needs uneven port/stbd turnbuckle counts by design. Set tension to a centered masthead — lock the main halyard, swing the tape to the same point each side — rather than to matched numbers, then record the offset.
Terminology (fleet convention): uppers run masthead → chainplate and lowers below the spreaders → chainplate — both Loos-tensioned and adjusted by wind (the tables above). The intermediates are the pre-bend / diamond wire up top. Heads-up: the North Sails A Scow guide swaps these labels — it calls the pre-bend wire the “uppers” and a chainplate wire the “intermediates” — so don't cross-wire the two if you read it alongside this card.
